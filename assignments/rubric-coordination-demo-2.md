# Rubric: Coordination Demo #2

**Total: 15 points** · Graded individually · Accept/Reject with comments · Rejected work may be resubmitted within 1 week

## Criteria

### 1. Thesis Connection & Iteration (4 pts)
*Does the demo test the thesis, and does it visibly build on Demo #1?*

| 4 — Exemplary | 3 — Proficient | 2 — Developing | 0 — Reject |
|---|---|---|---|
| Demo tests a sharpened version of the thesis — the demo note states what Demo #1 showed, what this demo changes, and what result would count as evidence for or against | Demo clearly related to thesis and to Demo #1, but the delta is incremental (same test, new surface) without a stated test condition | Demo touches the thesis domain but repeats Demo #1's approach; iteration is cosmetic | Demo does not test the thesis — "a beautiful tool that doesn't test the thesis is a reject" |

### 2. Working System (4 pts)
*Does the demo run, and does it surface document ↔ reality divergence?*

| 4 — Exemplary | 2.5 — Proficient | 1 — Developing | 0 — Reject |
|---|---|---|---|
| Live demo (or walkthrough) runs end-to-end; produces structured divergence findings (document reference, field observation, discrepancy type, severity/owner); failure modes handled or acknowledged honestly | System runs with minor gaps; output partially structured or requires manual patching shown in the demo | System runs only partially; claimed functionality not fully demonstrated | No working demo submitted, or the demo does not run |

### 3. Data Provenance (3 pts)
*Is the data real, synthetic, or hybrid — and is that documented?*

| 3 — Exemplary | 2 — Proficient | 1 — Developing | 0 — Reject |
|---|---|---|---|
| Data source documented (real with partner permission, or synthetic); synthetic data includes generation script + justification note explaining why the corpus is representative of the documents/observations being reconciled | Data source identified; synthetic script included but justification is thin | Data source vague; script or justification missing one element | Undocumented data of any kind — undocumented synthetic data is a reject |

### 4. Repo Quality (2 pts)
*Could someone else reproduce this?*

| 2 — Exemplary | 1 — Proficient | 0 — Reject |
|---|---|---|
| Repo contains code, data, all LLM prompts used, and dependencies (README/requirements); a newcomer could run it | Repo mostly complete; one element missing or stale | Repo missing code, prompts, or dependencies such that it is not reproducible |

### 5. Demo Note, Contribution & Evaluation Lab Worksheet (2 pts)
*Communication, accountability, and the attached worksheet.*

| 2 — Exemplary | 1 — Proficient | 0 — Reject |
|---|---|---|
| Demo note ≤500 words covering what changed since Demo #1, what was tested, and what it means for the thesis; contribution statements present for every team member; **Evaluation Lab Worksheet attached** to the submission | Note or contributions present but thin; worksheet attached but incomplete | Note missing or over-length; contribution statements missing; **or worksheet not attached** |

## Grading notes

- **Graded individually:** criteria 1–4 are scored on the team artifact but entered per student; criterion 5 is strictly individual. A student whose contribution statement is missing or generic loses criterion-5 points even if the team artifact is strong.
- **Accept/Reject:** an overall score of 11+ with no criterion at 0 is an Accept; any criterion at 0, or total below 11, is a Reject with comments and a 1-week resubmit window.
- **Evaluation Lab Worksheet:** attached to this submission and due the same day as Demo #2. A missing worksheet caps the submission at a Reject regardless of demo quality.
- **Mid-quarter reminder (not graded here):** practitioner interview transcripts are required in the repo for the Week 5 Mid-quarter Analysis. Teams that haven't scheduled interviews by this submission are flagged in comments.
- **Academic integrity:** undocumented synthetic data or unverifiable "live" demos presented as working systems are integrity violations, not just quality issues.
